What it is

Think of accumulatorA as a small notepad inside a computer that can remember one number.

The number is 4 bits, so it's four 1s and 0s, like 1010. A tiny computer called the VSM (Very Simple Microprocessor) uses it to hold a number it's about to do math on.

It has a few control wires. Each one does one simple job:

A: the number you want to save.
MainClock: a beat that ticks over and over. Saving only happens on a tick.
LatchA: the "save" switch. On means save A on the next tick. Off means ignore A and keep the old number.
ClearA: the eraser. Setting it to 0 wipes the number to 0000 right away.
EnableA: the "share" switch. On means put the number on the shared bus (IB) so other parts can read it. Off means stay quiet.
AluA and IB: the outputs. AluA always shows the saved number to the math unit (the ALU). IB shows it only when EnableA is on.

    The test drive

    My simulation ran for 240 nanoseconds (a nanosecond is a billionth of a second) and did six things in a row. Step through them.

    It's also fast. After the clock ticks, the new number shows up in about 0.43 nanoseconds. The layout version is a little slower (about 0.53 ns), because real wires and transistor edges add a bit of extra charge to fill. That's normal.

    If someone asks you

    Short answers you can say in your own words.

    What does accumulatorA do?

    It's a 4-bit register. It saves the input A when LatchA is on and the clock ticks, clears to 0000 when ClearA is 0, always sends the saved value to the ALU, and puts it on the bus when EnableA is on.

    What is it made of?

    Four flip-flops (one per bit), a NAND gate for the clock, a NOT gate for ClearA, and four tri-state buffers for the bus. 166 transistors total.

    What is a flip-flop?

    A circuit that remembers 1 bit. It only grabs a new value when its clock goes up. I built mine from 7 small gates from the class library.

    Why does it save when the clock goes down?

    The flip-flops' clock comes from a NAND of LatchA and MainClock. A NAND flips the signal, so when MainClock goes down, the flip-flop clock goes up, and that's when they save.

    What is a tri-state?

    A switch with three states: 1, 0, or "not connected". When EnableA is off, it disconnects from the bus so another part of the computer can use the bus.

    What's the difference between DRC and NCC?

    DRC checks the layout follows the manufacturing rules. NCC checks the layout matches the schematic.

    Why is the layout a bit slower than the schematic?

    The layout includes the real size of every transistor's edges, which adds a little capacitance. More capacitance takes slightly longer to charge.
